# First CRUD API

## Description

A RESTful CRUD API built with Express.js.

## Installation

npm install

## Run

node app.js

## API Documentation

http://localhost:3000/docs

## Endpoints

GET /tasks

GET /tasks/:id

POST /tasks
PUT /tasks/:id
DELETE /tasks/:id
GET /health

## Technologies

- Node.js
- Express.js
- Swagger UI
